# GS

**GS**是一个简单、高效的动态语言，语法和 go 近似，源代码被编译为字节码后解释执行，可以方便的与 go 类型集成。

## 语法

**GS**语法类似 go，主要差异：

- 简化了类型系统，采用动态类型，原生不支持指针，但可以操作 go 类型的指针
- 简化了作用域系统，作用域只有两级：函数内、全局

## 与go类型系统的集成

#### 访问go值

- 访问指针类型的成员：支持自动解引用，如 *struct.Field，可以直接写 struct.Field

#### 赋值go 值

当把 vm 中的值赋值给 go 类型时，遵循下面的原则：

- 基本类型赋值自动适配，如int->(uint,int32,int64 等)，float->(float32,float64)
- 复合类型赋值支持：
    - vm中 `{}` -> go `map[any][any]`
    - vm 中`[]` -> go `[]any`
    - go 中任意类型 -> go 中相同类型
    - 赋值给 go 中指针，除了类型要**严格**相同外，`*`操作符要求是对 env 的**直接操作**，如：
        - `*$.A.B = []{1,2,3}`
        - `*$.C = "aaaa"`
